## 一、项目概述

本项目是对 `/Users/lu/code/code/py/autofill/web` 前端项目的重构，使用 **Ant Design of Vue** 组件库替代原有的 naive-ui，实现相同的功能。重构后的项目位于 `/Users/lu/code/code/py/autofill/frontend` 目录下。

## 四、核心功能实现

### 4.1 路由系统

**文件**: `src/router/index.ts`

- 使用 Vue Router 4 的 `createRouter` 和 `createWebHistory`
- 动态路由加载：登录后从后端获取菜单数据，动态生成路由
- 路由守卫：
  - 未登录用户重定向到登录页
  - 已登录用户访问登录页重定向到首页
  - 动态加载用户菜单和权限

**静态路由** (`src/router/routes.ts`):
- `/login` - 登录页
- `/404` - 页面未找到
- `/403` - 无权限

**动态路由**: 从后端 `/base/usermenu` 获取菜单数据，构建为 `Layout` 布局下的子路由

### 4.2 状态管理

使用 Pinia 管理全局状态，分为四个模块：

#### 4.2.1 App Store (`src/store/modules/app.ts`)
- `collapsed`: 侧边栏折叠状态
- `isDark`: 深色模式（使用 `@vueuse/core` 的 `useDark`）
- `reloadFlag`: 页面刷新标志
- `aliveKeys`: 页面缓存键

#### 4.2.2 User Store (`src/store/modules/user.ts`)
- `userInfo`: 用户信息
- `tenants`: 租户列表
- `currentTenant`: 当前租户
- `isSuperUser`: 是否超级用户
- 方法：
  - `getUserInfo()`: 获取用户信息
  - `logout()`: 退出登录
  - `selectTenant()`: 切换租户
  - `fetchMyTenants()`: 获取我的租户

#### 4.2.3 Permission Store (`src/store/modules/permission.ts`)
- `accessRoutes`: 可访问路由
- `accessApis`: 可访问 API 权限
- `menus`: 菜单列表
- 方法：
  - `generateRoutes()`: 生成动态路由
  - `getAccessApis()`: 获取 API 权限

#### 4.2.4 Tags Store (`src/store/modules/tags.ts`)
- `tags`: 标签页列表
- `activeTag`: 当前激活标签
- 方法：
  - `addTag()`: 添加标签
  - `removeTag()`: 关闭标签
  - `removeOther()`: 关闭其他
  - `removeLeft()`: 关闭左侧
  - `removeRight()`: 关闭右侧

### 4.3 HTTP 请求封装

**文件**: `src/utils/request.ts`

- 基于 Axios 封装
- 请求拦截器：自动添加 `token` 到请求头
- 响应拦截器：
  - 统一处理错误码
  - 401 自动跳转到登录页
  - 全局错误提示（使用 Ant Design 的 `message`）

### 4.4 权限系统

#### 4.4.1 指令权限
**文件**: `src/directives/permission.ts`

- `v-permission` 指令：根据 API 权限控制元素显示/隐藏
- 超级管理员拥有所有权限

#### 4.4.2 菜单权限
- 动态路由根据后端返回的菜单数据生成
- 无权限页面显示 403

### 4.5 布局系统

**文件**: `src/layout/index.vue`

采用经典的侧边栏 + 顶部栏 + 内容区布局：

- **侧边栏**: `a-layout-sider`，包含 Logo 和菜单
- **顶部栏**: `a-layout-header`，包含面包屑、租户切换、用户信息
- **标签栏**: 多标签页导航
- **内容区**: `a-layout-content`，包含路由视图和过渡动画

## 五、页面功能实现

### 5.1 登录页 (`src/views/login/index.vue`)

- 用户名/密码登录表单
- 表单验证
- 登录成功后存储 token
- 多租户用户需选择租户

### 5.2 工作台 (`src/views/workbench/index.vue`)

- 欢迎语（显示当前用户名）
- 统计卡片（用户、角色、菜单、部门数量）
- 系统公告列表

### 5.3 个人中心 (`src/views/profile/index.vue`)

- 个人信息展示（头像、用户名、邮箱、角色）
- 头像上传
- 修改密码表单

### 5.4 用户管理 (`src/views/system/user/index.vue`)

- 用户列表（分页）
- 搜索：用户名、邮箱、租户
- 新增/编辑用户（模态框表单）
- 删除用户
- 重置密码
- 状态切换（启用/禁用）
- 多租户支持：超级管理员可选择租户

### 5.5 角色管理 (`src/views/system/role/index.vue`)

- 角色列表（分页）
- 搜索：角色名称、编码
- 新增/编辑角色
- 删除角色
- 分配权限（菜单树选择）

### 5.6 菜单管理 (`src/views/system/menu/index.vue`)

- 菜单树形列表
- 展开/收起全部
- 新增/编辑菜单（支持目录、菜单、按钮三种类型）
- 删除菜单
- 支持上级菜单选择

### 5.7 部门管理 (`src/views/system/dept/index.vue`)

- 部门树形列表
- 展开/收起全部
- 新增/编辑部门
- 删除部门
- 支持上级部门选择

### 5.8 租户管理 (`src/views/system/tenant/index.vue`)

- 租户列表（分页）
- 搜索：租户名称、联系人
- 新增/编辑租户
- 删除租户
- 用户管理（添加/移除租户用户）

### 5.9 API 管理 (`src/views/system/api/index.vue`)

- API 列表（分页）
- 搜索：API 名称、请求方法
- 编辑 API
- 删除 API
- 刷新 API（从后端重新同步）

### 5.10 审计日志 (`src/views/system/auditlog/index.vue`)

- 日志列表（分页）
- 搜索：操作人、操作类型、时间范围
- 显示操作详情

## 七、与后端的交互

### 7.1 API 前缀

所有 API 请求以 `/api/v1` 为前缀，通过 Vite 代理转发到后端 `http://127.0.0.1:8000`

### 7.2 认证方式

登录后获取 `access_token`，存储在 `localStorage` 中，每次请求通过 `token` 请求头传递

### 7.3 多租户支持

- 超级管理员可查看所有租户数据
- 普通用户只能查看当前租户数据
- 支持租户切换（顶部栏下拉选择）

## 十、注意事项

1. **图标映射**: 菜单图标使用字符串名称存储，渲染时通过 `@ant-design/icons-vue` 动态获取
2. **树形数据**: 部门、菜单使用 `a-tree-select` 和 `a-table` 的展开行实现
3. **权限控制**: 按钮级别使用 `v-permission` 指令，页面级别通过动态路由控制
4. **缓存**: 使用 `keep-alive` 缓存页面，通过路由的 `keepAlive` meta 控制
5. **响应式**: 使用 Ant Design Vue 的栅格系统实现响应式布局
