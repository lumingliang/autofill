写一个脚本
1. 查询下拉选项的public接口
传参 分类: 400电话  parent_id: 0 
获取到第一级的下拉数据
包括 {选项值} 和 {id}

然后调用 POST /api/public/autofill/field_group/upsert 接口 创建一个字段

    "page_name": "用户信息页",      // 
"group_name": "default",

字段列表传 [
    field_name: "一级事件类型"
    field_label: "一级事件类型"
    field_type: "select",
    fill_instruction: "请选择一级事件类型"
    options: [
        值为上面的{id}
        标签为上面的{选项值}
        fill_instruction为 请填写{选项值}
    ]
]








2. 接着对于上面的每个一级事件类型，调用
查询下拉选项的public接口
传参 分类: 400电话  parent_id:  {id}
获取到第二/三级的下拉数据
包括 {选项值} 和 {id}
然后需要把二三级展平，得到一个用 - 拼接的下拉列表。也包括
{id-id} {选项值(二级）-选项值(三级)}


然后每一个都调用 POST /api/public/autofill/field_group/upsert 接口 创建一个字段

    "page_name": "用户信息页",      // 
"group_name": "default",

字段列表传 [
    field_name: "{一级事件类型的值名称}-二三级"
    field_label: "{一级事件类型的值名称}-二三级"
    field_type: "select",
    fill_instruction: "请选择二三级事件类型"
    options: [
        值为上面的{id}
        标签为上面的{选项值}
        fill_instruction为 请填写{选项值}
    ]
]
